# Top 10 Locations Like PARC Bangna

Interactive single-page executive explainer for screening Bangkok corridors that may support a concept like PARC Bangna.

## Open the explainer

Open [`index.html`](index.html). The page is self-contained: Thai fonts, CSS, JavaScript, charts and the decorative motif are embedded in one file.

## Decision scope

The ranking identifies corridors for parcel search and field validation. It does not approve a plot, land purchase or investment.

The analysis uses:

- `Location = Traffic × Behavior`
- Traffic = Residents + Visitors + Commuters
- Behavior = concept fit + repeat routine + competitive white space + access/execution

Measured mobility, traffic direction, parcel access, customer origin and candidate-site operating evidence are still required.
